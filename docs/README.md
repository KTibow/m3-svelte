# M3 Svelte reference

This is the Markdown reference for M3 Svelte, for coding agents and other tools. It installs with
the package, so you can read or grep it at `node_modules/m3-svelte/docs/`. For demos and the full
docs, see the [website](https://kendell.dev/m3-svelte/).

| Read this                                      | When you want to                                             |
| ---------------------------------------------- | ------------------------------------------------------------ |
| [getting-started.md](./getting-started.md)     | set up a project                                             |
| [theming.md](./theming.md)                     | use the user's accent color, pin a brand color, bake a theme |
| [customizing.md](./customizing.md)             | build your own components, use tokens, avoid common mistakes |
| [components/README.md](./components/README.md) | use a specific component: examples, props, defaults          |
| [examples/](./examples/)                       | see whole apps: a todo list, a notes app, a docs site        |

To find something, try `grep -ril "date picker" node_modules/m3-svelte/docs`.
